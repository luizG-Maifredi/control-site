Política de Privacidade

Última atualização: 11 de novembro de 2026

Esta política explica quais dados o Control acessa, como eles são usados e como você pode desconectar o acesso a qualquer momento.

1. O que é o Control

O Control é um assistente que roda no computador do próprio usuário. Ele responde a perguntas e executa tarefas sobre o ERP da empresa (Sankhya) e sobre outras fontes que o usuário escolhe conectar, como arquivos do Google Drive e bancos de dados.

2. Dados que o Control acessa

  • ERP (Sankhya): dados da empresa acessados pela API configurada pelo próprio usuário, para responder às perguntas e executar as ações que ele confirmar.
  • Google: somente se o usuário conectar a conta. Nesse caso, o Control pede permissão de leitura do Google Drive (drive.readonly) e o endereço de e-mail da conta. O e-mail serve apenas para mostrar qual conta está conectada. O conteúdo de Planilhas, Docs ou Apresentações só é lido quando o usuário pede, por exemplo, ao colar o link de um arquivo na conversa.
  • Outros bancos de dados: somente os que o usuário cadastrar, e apenas com consultas de leitura.

3. Como os dados são usados

Os dados são usados exclusivamente para responder às solicitações feitas pelo usuário dentro do Control: mostrar números, tabelas e gráficos, comparar informações e preparar ações que o usuário confirma. O Control não usa os dados para publicidade, não os vende e não os usa para criar perfis.

4. Assistente de inteligência artificial

Para gerar as respostas, o conteúdo necessário para atender a cada pedido é enviado ao serviço de inteligência artificial da Anthropic (Claude), apenas para produzir aquela resposta. O Control não usa dados do usuário, incluindo os obtidos das APIs do Google, para desenvolver, melhorar ou treinar modelos de inteligência artificial.

5. Armazenamento

As configurações, os históricos de conversa e os tokens de acesso (incluindo o token do Google) ficam guardados no computador do usuário. O Control não mantém um servidor central com esses dados.

6. Compartilhamento

Os dados não são compartilhados com terceiros, exceto o envio ao serviço de inteligência artificial descrito no item 4, necessário para o funcionamento do assistente, ou quando exigido por lei.

7. Uso Limitado dos dados do Google

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google pelo Control seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

8. Como desconectar e apagar

  • No Control: Configurações › Google › Desconectar. O token é apagado do computador e o acesso é revogado no Google.
  • Pela sua conta Google: em myaccount.google.com/permissions, remova o acesso do Control.
  • Para apagar todos os dados do Control, basta remover a pasta de dados do aplicativo no seu computador.

9. Contato

Dúvidas sobre esta política podem ser enviadas pela página de contato do Control.

10. Alterações

Esta política pode ser atualizada. A data no topo da página indica a última alteração.
